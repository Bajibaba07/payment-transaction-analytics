# Merchants Table Design

| Column Name | Data Type | Description |
|-------------|-----------|-------------|
| merchant_id | VARCHAR | Unique merchant identifier |
| merchant_name | VARCHAR | Name of the merchant business |
| merchant_category | VARCHAR | Category of business (Fashion, Grocery, Retail, Electronics, Education, Restaurants, Entertainment, etc.) |
| city | VARCHAR | City where merchant is located |
| state | VARCHAR | State/Province where merchant is located |
| contact_person | VARCHAR | Name of primary contact person at merchant |
| email | VARCHAR | Email address of merchant contact |
| phone | VARCHAR | Phone number of merchant contact |
| registration_date | DATE | Date merchant registered in the system |
| merchant_status | VARCHAR | Current status of merchant (Active, Suspended, Pending) |
