# Customer Table Design

| Column Name | Data Type | Description |
|-------------|-----------|-------------|
| customer_id | VARCHAR | Unique customer identifier |
| first_name | VARCHAR | Customer's first name |
| last_name | VARCHAR | Customer's last name |
| gender | VARCHAR | Customer's gender (Male, Female) |
| age | INT | Customer's age |
| email | VARCHAR | Customer's email address |
| phone | VARCHAR | Customer's phone number |
| city | VARCHAR | City where customer is located |
| state | VARCHAR | State/Province where customer is located |
| occupation | VARCHAR | Customer's occupation |
| annual_income | INT | Customer's annual income in local currency |
| registration_date | DATE | Date customer registered in the system |
